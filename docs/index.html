OpenLP Cloud Sync

Keep your OpenLP song library in sync across every computer you run — automatically, over your own Google Drive.

Download the installer Source code

What it does

OpenLP Cloud Sync is a plugin for OpenLP, the free and open-source church presentation software. Once installed, it backs up your song library to a folder in your Google Drive and merges changes from your other machines — a true three-way sync, so edits made on any computer propagate everywhere without clobbering each other.

  • Automatic merging — additions, edits, and deletions on any machine are reconciled against a base snapshot, not blindly overwritten.
  • Tiny backups — only the song database syncs (a few KB); Bibles, themes, and images stay local to each machine.
  • Minimal Google permissions — the app requests only the drive.file scope, so it can touch only the backup files it creates. It cannot see any other file in your Drive.
  • No server, no account, no tracking — your data moves between your computers and your Drive, and nowhere else. Read the privacy policy.

Get started

  1. Download and run the Windows installer from the releases page.
  2. Restart OpenLP, open the Cloud Sync plugin tab, and click Sign in with Google.
  3. Click Sync now — repeat on each computer.

Full walkthrough and troubleshooting are in the README.
